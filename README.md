# 研究所考試資訊搜尋網站

此網站專門提供台灣各大學研究所考試資訊，特別聚焦於半導體元件物理、電子學、工程數學三個科目。

## 功能特色

1. **搜尋功能**：可依學校名稱、系所、科目或考試大綱關鍵字進行搜尋
2. **完整資訊**：包含各校系所的考試科目大綱詳細說明
3. **錄取率資訊**：新增各校近年錄取率參考資訊
4. **歷年參考**：提供近年參考簡章連結及考試時間資訊
5. **響應式設計**：適應桌機與行動裝置瀏覽

## 資料來源

目前網站包含以下學校的樣本資料：
- 國立台灣大學電機工程學研究所
- 國立清華大學電子工程學研究所  
- 國立成功大學微電子學研究所
- 國立交通大學電子工程學研究所
- 國立中央大學光電科學與工程學研究所

每個學校都有：
- 三個主要科目的詳細考試大綱
- 錄取率參考資訊（約數值，僅供參考）
- 歷年可參考年度資訊
- 考試時間與地點說明
- 連結至官方簡章頁面

## 使用方式

1. 直接在搜尋框輸入關鍵字（如「台大」、「半導體」、「電子學」）
2. 按下搜尋鈕或按Enter鍵
3. 查看匹配結果的詳細資訊，包括錄取率

## 注意事項

- 目前資料為樣本資料，實際應用時應替換為各校官方最新公告
- 錄取率為近年參考值，實際錄取率會因年度而異
- 考試內容可能每年有所變動，請務必參考該年度簡章
- 網站設計為前端靜態頁面，可直接開啟index.html使用
